# CLAUDE.md

Guidance for AI assistants working in this repository. This file lives only on the
`local-fixes` branch — do not merge it into fix branches destined for upstream PRs.

## What this repo is

Tim's fork of the Synthstrom Audible Deluge firmware (C++, ARM bare-metal).

- `origin` = git@github.com:cyface/DelugeFirmware.git (the fork)
- `upstream` = https://github.com/SynthstromAudible/DelugeFirmware.git

## Branch workflow

- `main` mirrors `upstream/main`. To sync: fast-forward `main` from `upstream/main`,
  push to `origin`, then merge `main` into `local-fixes`.
- New fixes/features get their own branch **cut from `main`** (so they stay PR-able
  upstream), then get **merged** into `local-fixes`.
- `local-fixes` is the accumulator branch that gets built and flashed to hardware.
  It is merge-based — never rebase it. Merging a new fix branch often conflicts in
  shared registration points (settings enums, menu arrays, l10n files); resolve by
  keeping both sides.

## Building

```
./dbt build release
```

Output: `build/Release/deluge.bin` (and `deluge.elf`). A full build takes a few
minutes; the "LOAD segment with RWX permissions" linker warning is normal.
After merging anything into `local-fixes`, rebuild to verify before flashing.

Pre-commit hooks run clang-format and may modify files, failing the first
`git commit` — just `git add -A` and commit again.

## Gotchas

- **l10n strings**: `src/deluge/gui/l10n/g_english.cpp` and `g_seven_segment.cpp`
  are AUTOGENERATED by `generate.py` during the build. Edit `english.json` /
  `seven_segment.json` instead (plus the enum in `strings.h`); direct edits to the
  `g_*.cpp` files are silently regenerated away. 7-segment strings are max 4 chars.
- **Community feature settings** (the usual way to make a change toggleable):
  add to the enum in `src/deluge/model/settings/runtime_feature_settings.h`, set it
  up in `runtime_feature_settings.cpp` `init()`, register a menu item in
  `src/deluge/gui/menu_item/runtime_feature/settings.cpp` (both the instance and the
  `subMenuEntries` array), and add l10n strings. Values persist to
  `SETTINGS/CommunityFeatures.XML` on the SD card.
- The `.idea/` directory is intentionally tracked — never suggest removing or
  gitignoring it.

## Testing without hardware

DelugEmu (QEMU-based emulator) can boot a built `deluge.bin`; panel interaction and
screendumps work over QMP, and sysex/file transfer over UDP MIDI. See the notes in
Claude's project memory (`delugemu-launch`, `delugemu-testing`) for paths and
invocation details.
